# Web API Core Seed v2.0.1 — October 2026 .NET security servicing

This patch release updates the `dotnet new` template's .NET SDK and Docker runtime baselines, following the [October 2026 out-of-band .NET security update](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/), including CVE-2026-111497.

## Changes

- The generated project's `global.json` requires **.NET SDK 10.0.403**.
- The generated `Dockerfile` uses **`mcr.microsoft.com/dotnet/sdk:10.0.403`** for build and **`mcr.microsoft.com/dotnet/aspnet:10.0.14`** for its final runtime stage.
- Template smoke tests verify these version baselines in the generated files.
- The publication workflow aligns the package, tag, release notes and assets at **2.0.1**. CI, CodeQL and template smoke tests must pass on the exact source commit; SHA-256 checksums are verified after publication.
- The existing **v2.0.0** tag and GitHub Release remain unchanged.

## Install or upgrade

The distribution channel is **GitHub Release assets, not NuGet.org**. Once published, download `RodriOliveira.WebApiCoreSeed.Templates.2.0.1.nupkg` and `SHA256SUMS.txt` from [Release v2.0.1](https://github.com/rodri-oliveira-dev/web-api-core-seed/releases/tag/v2.0.1).

```bash
sha256sum --check SHA256SUMS.txt
dotnet new uninstall RodriOliveira.WebApiCoreSeed.Templates # if already installed
dotnet new install ./RodriOliveira.WebApiCoreSeed.Templates.2.0.1.nupkg
dotnet new webapi-seed -n SampleApi
```

## Security boundary and deployment

This release **does not establish that the sample uses affected Brotli decompression APIs**. It provides a serviced toolchain baseline for new projects. Installing a new template **does not update existing generated applications, running containers, or the host-installed .NET runtime**. Rebuild Docker images with `--pull` and redeploy affected applications; update host runtimes as applicable. Self-contained applications must be republished with a serviced SDK.

See the [release checklist](release-checklist.md) and [template distribution guide](../template-distribution.md). The repository remains a development/reference seed, not a production security certification, and no repository-wide open-source license or NuGet.org publishing channel has been selected.
