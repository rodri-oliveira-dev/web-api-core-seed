# Web API Core Seed v2.0.1 - .NET 10 security servicing

Patch release of the installable `dotnet new webapi-seed` project template. It incorporates Microsoft's October 25, 2026 out-of-band security servicing baseline for newly generated projects.

## Changes

- Updated the packaged `global.json` to require **.NET SDK 10.0.403**.
- Updated the packaged `Dockerfile` build image to **`mcr.microsoft.com/dotnet/sdk:10.0.403`** and ASP.NET Core runtime image to **`mcr.microsoft.com/dotnet/aspnet:10.0.14`**.
- Strengthened the package smoke check to verify that the generated template archive actually contains the intended SDK and runtime image versions and matches the release package version.
- Aligned the release workflow and bilingual onboarding instructions with version **2.0.1**.

These changes include the security fix merged in [PR #57](https://github.com/rodri-oliveira-dev/web-api-core-seed/pull/57). See [Microsoft's .NET October 2026 out-of-band security updates](https://devblogs.microsoft.com/dotnet/dotnet-october-2026-oob-security-updates/) for vulnerability details, including **CVE-2026-111497**. This project does not claim confirmed direct use of the affected Brotli decompression APIs.

## Install the versioned template

Download `RodriOliveira.WebApiCoreSeed.Templates.2.0.1.nupkg` and `SHA256SUMS.txt` from the **GitHub Release v2.0.1** assets. The package is not published to NuGet.org.

```bash
sha256sum --check SHA256SUMS.txt
dotnet new install ./RodriOliveira.WebApiCoreSeed.Templates.2.0.1.nupkg
dotnet new webapi-seed -n SampleApi
cd SampleApi
dotnet restore SampleApi.slnx
dotnet build SampleApi.slnx --configuration Release --no-restore
```

To update a previously installed template, uninstall its package and install the new `.nupkg`. The patch does **not** update projects you have already generated.

## Deployment and security notes

- A template archive is **source/configuration distribution**, not a self-contained .NET runtime. Applications running with a framework-dependent deployment still need the serviced .NET 10 runtime on the target host.
- Rebuild and redeploy container images using the patched base images; updating the template or `global.json` does not replace already deployed containers.
- The sample API remains a reference implementation, not a production-hardened blueprint; continue to assess secrets, dependencies, ingress settings, deployment and database migrations.
- The historical **v2.0.0** GitHub Release, tag and assets remain unchanged.
- GitHub Releases remain the distribution channel. No NuGet.org publication or license grant is implied; the repository still requires owner review of licensing and provenance.

## Verification and provenance

The release automation validates successful CI, CodeQL and template-smoke checks at the exact `main` commit. It packages the template, installs and tests that **same `.nupkg`**, creates SHA-256 checksums, publishes the assets, and downloads/verifies them without moving existing tags.
