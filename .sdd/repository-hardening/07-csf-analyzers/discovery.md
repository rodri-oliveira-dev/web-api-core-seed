## Namespace discovery for `ARC002`

Current layout is physically closer to modular/hexagonal boundaries, but several namespaces remain intentionally legacy:

- Domain model namespaces: `WebApiCoreSeed.SampleRestaurant.Models*`.
- Application/use case namespaces: `WebApiCoreSeed.SampleRestaurant.Services`, `WebApiCoreSeed.SampleRestaurant.Notificacoes`.
- Ports/contracts namespaces: `WebApiCoreSeed.SampleRestaurant.Intefaces*`, `WebApiCoreSeed.SampleRestaurant.Interfaces*`, `WebApiCoreSeed.SampleRestaurant.Application.Contracts*`.
- Infrastructure namespaces: `WebApiCoreSeed.SampleRestaurant.Infrastructure*`, `WebApiCoreSeed.Identity.Infrastructure*`.

Future `ARC002` configuration must represent those actual namespaces, not only the physical folders `Domain` and `Application`.
