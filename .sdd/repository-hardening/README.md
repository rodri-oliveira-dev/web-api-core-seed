# Repository Hardening

Esta etapa padroniza metadados e arquivos operacionais apos a Fase 4, sem alterar codigo produtivo, projetos ou pacotes.

## Sequencia de prompts

1. Higienizar metadados e arquivos operacionais.
2. Padronizar layout e namespaces.
3. Adotar Central Package Management.
4. Padronizar build e estilo.
5. Migrar solution para SLNX.
6. Adotar CSF.Analyzers.

## Escopo

- Remover integracoes ativas remanescentes de Sonar.
- Modernizar `.gitignore`.
- Criar `.gitattributes`.
- Criar `.dockerignore`.
- Inventariar arquivos operacionais.
- Preparar uma baseline limpa para os prompts seguintes.
