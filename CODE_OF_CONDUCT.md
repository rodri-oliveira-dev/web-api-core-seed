# Code of Conduct

## Our standards

This project welcomes contributors from different backgrounds and experience levels. Be respectful, considerate and constructive in issues, code reviews and discussions.

Expected behavior:
- Focus feedback on technical facts, reproducible behavior and actionable suggestions.
- Assume good intent while remaining open to correction.
- Respect privacy, accessibility and diverse viewpoints.
- Credit contributors appropriately and accept technical disagreement without hostility.

Unacceptable behavior includes harassment, personal attacks, intimidation, discrimination, threats, publishing private information without consent, and persistent disruption of project discussions.

## Reporting and enforcement

If you experience or observe unacceptable conduct, contact the repository maintainer **privately** through an available channel on their [GitHub profile](https://github.com/rodri-oliveira-dev); avoid exposing personal details in public issues. Include the relevant links, a factual description and what help you need.

Maintainers may request edits, moderate discussions, remove inappropriate content or restrict participation based on the situation. Reports will be handled with discretion where practical; confidentiality cannot be guaranteed on public GitHub threads.

## Scope

This code of conduct applies to project collaboration spaces and community interactions where participants represent the project. Security vulnerabilities should instead follow [SECURITY.md](SECURITY.md).
